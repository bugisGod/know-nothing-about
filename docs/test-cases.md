## 豁免项（记录理由）

1. 相关知识推荐区块——单专题无对象，等第二个 series
2. pagefind 中文分词——已知平台限制
3. 真机触感——headless 局限
4. 压测/多浏览器——范围外
5. 深色主题切换——全站固定暗色
