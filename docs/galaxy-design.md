## 一、设计理念

把博客变成一张可以探索的银河星图。用户不是在「浏览文章列表」，而是在一片知识宇宙中探索。

- **银河系 = 整个博客**
- **银河中心 = 个人主页（scio.）**——你的个人信息、思想起点
- **星团 = 文章分类**——不同质量团有不同的结构和分布
- **恒星（文章星）= 单篇文章**——大小、亮度、光晕区分重要性
- **星云 = 柔弱的光晕粒子效果**——纯装饰，营造宇宙空间感，不承载信息
- **星际连线 = 文章之间的关联**——共享标签自动生成，`related` frontmatter 手工覆盖
- **新星 = 最近发布的文章**（45 天内自动）
- **亮星 = 置顶/精选文章**（`pinned: true`）
- **背景星 = 装饰性星空**

三个入口各司其职：

| 操作 | 意义 |
|---|---|
| EXPLORE | 不知道看什么 → 自由漫游整个银河 |
| 点击星团 | 知道想看哪个领域 → 拉近聚焦该分类 |
| 搜索 | 明确知道要找什么 → 快速通道 |

**核心一句话**：默认状态不是静态地图，而是一座会呼吸的银河；Explore 不是让银河动起来，而是让银河开始回应你。

## 二、视觉体系

### 2.1 银河结构（俯瞰 + 34° 倾角，顶边向屏幕深处倾倒）

- 四臂俯瞰螺旋：`ARMS 4 / SWEEP 5.0 rad（≈0.8 圈/臂）/ 盘径 GR24`
- 旋臂拖曳方向与自转一致（顺时针，物理正确的 trailing arms）
- 核心暖白（对照真实银河摄影去土黄）+ 核球密集 + 核心辉光 + 中心星芒粒子团（scio. 主星）
- **星族点缀**：~2.5% 主角星——橙红巨星 `#ffb070` / 蓝白年轻星 `#a9c8ff`（摄影图里最抓眼的两种色）
- **粒度幂律**：`rand^4` 大小分布——海量 1px 级微星融成连续星海 + 极少数大星（深邃感 = 大小跨度，不是数量）
- 分层差速自转：核心 0.007 : 内盘 0.014 : 外盘 0.0084（≈方案比例 0.05:0.10:0.06），背景星幕不动
- 密度自适应：粒子数 × `DN = areaK^0.85`（手机自动降载，375×812 → 0.29）

### 2.2 分类星团的视觉结构（form 语义）

| form | 结构 | 当前分配 |
|---|---|---|
| dense | 密集、结团星团（Plummer 密度向心收紧） | 学习笔记 |
| spiral | 较为规则螺旋分布（团内双螺线带） | 前端 |
| scatter | 分散、星系分布较广（宽度并入半径收放） | 项目 |
| natural | 随机、自然的分布（黄金角） | 新分类默认 |

**边界 = 组合元素，不是一条线**（2026-09-30，方案图《星团边界的设计方案》定稿）：

- **密度场**：背景星 Plummer 分布向心密集 + 径向渐隐（rim）+ 多边形轮廓包络——范围由密度读出
- **轨道弧**：每团 2~3 段 60~110° 的部分弧（永不闭合），绕 X 轴各倾 ±0.28~0.55 rad 的 3D 翻角，星尘粒子两端渐隐——near 0.25 / hover 0.6 / explore 0.85 / focus 0.62 分级浮现
- **团内微连线**：同团文章星两两短弧（亮度 0.26，暗于跨团知识连线），探索态随知识网络一同浮现
- **错误示例（勿回退）**：虚线点圈勾封闭图形 = 2D 平面感、像画了个圈（方案❌）
- 剪影函数 `r(θ)`（3~5 边+谐波，团 key 哈希）供密度场/轨道弧/文章星共用；基础半径 scatter ×1.05 / 其余 ×0.95
- 内容层远端可见性：uFadeLo 0.85（星团转到盘面远端不被空气透视吞掉；银河本体保持 0.55）

### 2.3 恒星的层级与状态

| 层级 | 条件 | 视觉 |
|---|---|---|
| 普通文章 | — | 域色小星 |
| 新星 | 发布 45 天内自动 | ×1.35 暖金倾向 + 脉冲光环 + tip「新星」前缀 |
| 亮星 | `pinned: true` | ×1.8 + 常驻淡金光晕 + tip「亮星」前缀 |
| 当前 hover | 鼠标命中 | 本体放大 1.65 倍渐变提亮 |

### 2.4 星云（纯装饰）

星云 = **随机但具有密度结构**的微弱粒子/雾状光效。要害是「有结构的密度场」，不是均匀噪点：

- **密度场骨架**：18 个云核（太少→团块生硬，太多→退化成均匀噪点），按 `rad^1.5` 加权采样
- **三类粒子**：78% 云核粒子（向心高斯——云心密、边缘指数稀疏）+ 14% 丝缕（两核之间带弯曲的桥，云才自然连片）+ 8% 弥散底噪（整盘极稀薄，避免云间突兀空档）
- **双层**：云雾层 ≈2600×DN 中大柔斑（重叠成雾）+ 微尘层 ≈6600×DN 小粒子撒在云上；两层 churn 异速错动
- **亮度分级**（每千颗）：70% 若有若无 / 20% 轻微可见 / 8% 偶尔闪 / 2% 明显微光；亮档混高饱和色相（additive 下暗粒子只呈灰白，色相靠亮粒子显现）
- **加性混合**：雾只能加光——普通混合下暗粒子会把背景压黑（历史坑）
- 独立漂移：不跟随银河自转，云雾层/微尘层异向异速 + 正弦漂浮，绝不同步闪烁
- **与星团/分类完全解耦**：不承载信息、不可点、**刻意无边界**（可穿过星团区域）——「星团有语义、星云只是环境」的对比正来源于此

### 2.5 用色

- 主色调：深空蓝 + 星光色系（少量点缀色），克制、梦幻、沉浸、深邃
- 页面底 `#060709`；核球金黄 `#ffe0b0→#fff0d4`；盘星冰蓝白 `#d4dced` ↔ 暖金 `#ffd9a0`
- 分类域色与全站分类标识色一致（`CATEGORIES.color`）：学习笔记 `#93a9d6` 雾蓝、前端 `#a892d8` 雾紫、项目 `#ffc46b` 琥珀
- 字体：Noto Serif SC 600 + Inter（站点灵魂字体，星图标题卡同源）；琥珀句点为站点符号

## 三、交互设计

### 3.1 点击优先级（核心规则）

```
文章星（30px）   → 最高优先级：点到文章星永远打开文章
星团区域（88px） → 第二：没点到文章星才判定星团
银河中心（42px） → 主星入口
银河背景         → 最低：无操作
```

### 3.2 星团交互状态机

星团三层结构：① 区域（光晕+边界）② 视觉核心（背景星+光晕）③ 文章星（可点，永远最高优先级）。

| 状态 | 星团 | 文章星 |
|---|---|---|
| idle 默认 | 淡淡聚集、无边界 | 正常显示 |
| near 靠近（~150px） | 微光晕（预响应） | 正常 |
| hover 悬停 | **虚线星尘边界**浮现 + 名称提亮 + 团内星提亮 | 成员星提亮 1.35、他团标签降权 |
| focus 锁定（点击） | 边界最实 + 细轨道线环绕（慢转）+ 镜头动态对准聚焦 + focus bar（名称/篇数/话题/打开分类页） | 成员星降权 ×0.85（「退一步」）；hover 成员星时该星突出（环+放大+信息卡） |
| dim 他团 | 降权变暗 | — |
| 退出（Esc/返回/空白） | 镜头回全景，全部恢复 | — |

星团边界不显示于默认态（画面干净优先）；星团入口三个：点名称标签、点星团区域（88px 引力区拾取）、EXPLORE 态靠近点击。悬停圆环只给文章星——星团用「光晕+边界」表达，不套大圆环。

### 3.3 EXPLORE = 自由漫游（不指向任何分类）

点击后：镜头缓缓后退（3 秒，camZ +14）→ 完整展示银河 → **探索层开启**：

- 视口边框浮现（呼吸细线框，模式标识）
- 底部「✦ EXIT EXPLORE」按钮 + 操作提示（首次，数秒淡出）
- 星尘涌动渐强、自转 ×2、关系线从隐藏到显现
- 顶部胶囊条隐藏（边框 + EXIT 即模式标识）

退出：再点 EXPLORE / Esc / EXIT 按钮 → 回凝视态。

### 3.4 动态对照表

| 维度 | 默认（凝视） | Explore（探索） |
|---|---|---|
| 银河 | 慢慢呼吸（±2.6% 脉动、亮度 ±10-12%） | 主动响应（自转 ×2、涌动渐强、引力） |
| 星云 | 缓慢漂移（异向异速 ~0.1px/s） | 更明显流动 |
| 星星 | 呼吸（周期 8-21s、随机相位） | 可交互（hover 放大、点击） |
| 星团 | 安静 | 鼠标靠近会唤醒 |
| 关系线 | 隐藏（0.05） | 显现（0.88） |
| 鼠标 | 轻微视差（相机 ±1.25 单位） | 控制空间（引力 + 缩放 + 旋转） |
| 拖动 | 不需要 | 可以 |
| 缩放 | 不需要 | 可以（普通滚轮 + 双指） |
| 核心感觉 | 凝视 | 探索 |

## 四、内容运营指南

### 加文章
1. `src/content/notes/<分类>/新文章.md`，frontmatter 至少 `title`
2. 可选：`tags`（自动生成星际连线）、`pinned: true`（亮星）、`related: [slug]`（手工连线覆盖）

1. `src/content/notes/` 建新文件夹 + `src/config.ts` 的 `CATEGORIES` 加一行（label/desc/color，可选 form）
2. 自动生成：旋臂上新星团（域色粒子群 + 标签 + 分类页 + 列表分组）

### 星团颜色
`CATEGORIES.color` 与全站分类标识一致（列表页/星图同色）。改色即全站同步。

## 六、技术实现要点（维护者须知）

- 核心文件：`src/components/BrainGraph.astro`（星图全部）、`src/pages/index.astro`（数据/布局）、`src/config.ts`（分类）、`src/content.config.ts`（schema）
- 数据流：构建期 `index.astro` 从 content collections 算出 `clusters/stars/links` → JSON 内嵌 → 客户端 three.js 渲染
- 星团位置：`clusPos` 沿旋臂按序摊开；文章星位置：slug 哈希 + form 散布（确定性，加内容不搬家）
- **ShaderMaterial 的透明度必须写 `uniforms.uOpacity.value`**——`.opacity` 属性不进渲染（历史静默失效坑）
- **自转必须增量积分**（`rotation += dt × 速率`）——绝对角度式在速率切换时会整盘回跳
- 每次构建后需重启 `astro preview`（sirv 缓存产物清单）
- 4460 端口的旧 python 服务目录内容过期，验证一律用 4321
- 调试口：`?debug=1` 暴露 `window.__gal`（tilt/cam/scene/proj/focusState/uMouseScreen）
