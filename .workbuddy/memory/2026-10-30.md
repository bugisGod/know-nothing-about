## 补完方案 A（用户批准，2026-10-31 凌晨实施）

### 改动 1：一条 CSS 替掉死规则（无需改 JS）
把 496 行那条**从未被 JS 添加的死规则** `.galaxy-focus.hidden-for-explore{opacity:0}`
换成 `.graph-frame :global(.galaxy-focus.explore .gf-back){display:none}`。
**为什么不用改 JS**：`exitExplore()` 里 `focusBar.classList.remove('explore')` 位于
`if (!keepUI)` 分支**之外**，所以聚焦态（走 exitExplore(true)）会自动移除该类、
返回按钮随即恢复为「← 返回全景」；漫游态 enterExplore 加上该类 → 按钮隐藏。
→ 漫游态 = 顶部胶囊纯模式牌 + 底部 EXIT 唯一出口；聚焦态 = 顶部返回唯一出口。

### 改动 2（顺带）：删掉回滚带回的 `.gf-back` 双重绑定
回滚恢复到 a9ca563 后，3606 与 3665 各有一次 addEventListener。点一次连跑两个 handler：
① flyBack → resumeExplore → enterExplore 刚接回漫游；② 看到 exploreMode 已 true →
立刻 exitExplore 又退掉。**表现：聚焦态点「← 返回全景」= 直接退出探索**（实测复现）。
删掉 3606 那条冗余绑定即可。（注：这个 bug 在 a9ca563 就存在，
用户早先反馈的「探索态点团拉近 → 点空白 → 探索态没了」正是它。）
