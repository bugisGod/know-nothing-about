### ★★ 踩到 Astro scoped style 的 :global() 陷阱（重要，可复用）
`:global(.父) .子` 这种写法，Astro 只把括号内去 scope，**括号外的 `.子` 会被补上
`[data-astro-cid-xxx]`**。而 `.cl-count` / `.cl-topics` 是 JS 动态创建的元素，没有该属性
→ **选择器永不匹配**。编译产物实锤：
```css
.cluster-label[data-state=hover] .cl-topics[data-astro-cid-ssexyeyx]{opacity:.85}
```
**修法**：整段后代选择器一起包进 `:global(.cluster-label[data-state="hover"] .cl-topics)`。

**由此发现一个长期失效的隐藏 bug**：`.cl-count`（「NN ARTICLES」篇数）的 hover 规则同样被 scope，
所以**篇数从设计上（注释写着"hover 再出现"）就一直没显示过**，一直没人发现。已一并修复。
