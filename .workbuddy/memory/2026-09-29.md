## 星团交互层级重构（用户定稿规范落地）
用户规范核心：星团靠「外围空间结构」表达自己，不靠把星变亮；三层 = ①几乎不可见的区域 ②极淡光晕+代表亮星 ③文章星（可点，永远最高优先级）。

### 状态机（patch-cluster-hierarchy.py，17 锚点，备份 BrainGraph.bak3.astro）
- 每团状态插值：prox(邻近度)/near/hov/foc/dim，主循环统一写 halo/bounds/bgStar/label/starSize（原多处写 starSize 互相覆盖 → 收敛到唯一写入点）。
- clusterHalo：每团一个 AdditiveBlending 光晕 Sprite（haloTex），op=0.055+near·0.05+hov·0.085+foc·0.10，×他团降权（focus 时他团 0.32/hover 时 0.5）。
- clusterBounds/clusterBgPts 改每团独立 Points（NC=3 个对象，可独立降权）。
- 边界 op = max(explore·0.5, near·0.13, hov·0.34, foc·0.6)·dim。
- 文章星倍率：聚焦团 0.82（退一步）/他团 0.55；hover 星团 团内 1.18/团外 0.86；hover 单星 ×hoverScale（重新亮起）。
- hover 星团不弹信息卡（星团是空间不是对象）→ 只边界浮现+名字提亮+cl-count 浮出（CSS data-state）；触屏 tap 仍走底部卡两段式。
- 引力区拾取：clusterScreenR(k)=盘内正交两方向投影平均半径，HIT= max(40, R·1.2+22)（随缩放/视角伸缩）；pick 保持 star>cluster>home？→ 实为 home>star>cluster（星最高优先级已验证：点星团中心命中文章星弹文章卡）。
- 标签：dataset.state=idle/hover/focus/dim + JS 写 op（clusLabelOp），focus 态字号加大 #ffc46b；吸附=标签朝鼠标偏移 ×(0.35+prox·0.65)。
- 聚焦态标签：聚焦团=视觉中心（放宽裁剪，op 1, state focus），他团隐藏（原 focusT>0.02 全部 inGuard 的 bug）。

### 两个关键 bug（本次最重发现）
1. **聚焦后画面全黑**：FOCUS_CAM_Z 硬编码 -23.9，但 58° 倾角把旋臂星团世界 z 抬到 -30+y_local·sin(rx)（±7），「前端」团 z≈-23 落到相机背后 → NDC z=1.247 被裁。修：flyTo 缓存 rel.z（相对 tilt），主循环 camZ=tilt.z+rel.z+FOCUS_DIST(6.1) 动态计算。三团聚焦 proj 全部 ~(713,360) z=0.968 ✓
2. **相机游移破坏对准**：±0.5 单位正弦游移在近距 6.1 下=±150px 画面偏移。修：drift=1-focusT 乘游移与鼠标视差。
