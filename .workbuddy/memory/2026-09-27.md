## 星空视频迭代（概念图 → 视频）
- 用户要求：基于首页概念图生成 5 秒 1080P 星河缓慢转动 + 繁星忽明忽灭的 MP4；先要清理所有 UI/标签文字，再加几颗亮星。
- 处理链路：image-edit `erase` 操作清掉 UI（hero 名言、3 个星名标签、右侧文章面板、页头/页脚/版权/导航、×关闭按钮）→ Python+Pillow 在已擦除底片上手动叠加 8 颗径向渐变亮星（4 蓝白 + 2 暖白 + 2 琥珀，位置散布避开银河带主体）→ VideoGen 图生视频。
- 关键坑：
  - `erase` 用了系统 hermes venv（已装 requests），managed venv 装不上 requests（无网络/索引失败）。
  - Pillow 亮星合成踩了几个坑：先画晕再 `layer.filter(blur)` 后 ld 失效导致后续画到空气 → 拆成 spike/halo/core 三层独立 ImageDraw；外核 alpha 方向反了变成甜甜圈 → 改成单一高斯型径向渐变（u→0 时 alpha 最高，颜色 mix 到白）。
- 留待沉淀的复用资产：`/.workbuddy/overlay-bright-stars.py` 是独立可重用的「在暗底片上叠亮星」工具（参数化位置/半径/色温）；首次帧图 `/.shots/firstframe-clean.png` 干净底片+8 颗亮星，可直接喂视频生成。

## 视频超分（OpenCV ESPCN 2x）
- 用户想突破 VideoGen 1080P 上限，用 AI 把视频超分到 2 倍。
- 链路：`opencv-contrib-python-headless 5.0.0` 提供 `cv2.dnn_superres`；从 `fannymonori/TF-ESPCN` 仓库下到 `ESPCN_x2.pb`（85KB，protobuf 格式）；脚本逐帧 `sr.upsample()` → `cv2.VideoWriter mp4v` 写出。
- 实测：1764×1176 / 24fps / 121 帧 → 3528×2352 ≈ 3.5K，CPU ESPCN 跑 69 秒。
- 资源：模型缓存 `.workbuddy/models/ESPCN_x2.pb`；脚本 `.workbuddy/upscale-video-espcn.py` 参数化（in/model/out）。
- 坑：opencv 官方仓库里 sample .pb 路径 404；正确源是 `fannymonori/TF-ESPCN` 子模块。`pip install basicsr/realesrgan` 会卡 cv2/git-version 依赖，放弃。
