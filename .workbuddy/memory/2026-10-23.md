## ZCode 移动端远程控制二维码截取

- 任务：帮用户打开 ZCode「连接手机」并截二维码。入口 = ZCode 左下角侧栏手机图标 →「移动端远程控制」弹窗（左侧二维码 + 连接地址，右侧 Bot Channel）。
- 环境坑（可复用）：
  - PowerShell `Add-Type` 被 sandbox 拦（编译 .NET）；从 Bash 里调 powershell 也被拦，必须走 PowerShell 工具。
  - pip 内网镜像装不了 mss → 用 ctypes + GDI（BitBlt/GetDIBits）截屏 + 手写 PNG 编码（zlib），零依赖。脚本在 `.shots/cap.py`（用法：`cap.py full` / `cap.py crop x y w h out scale`）。
  - **截屏必须 `SetProcessDPIAware`**，否则 GetSystemMetrics 返回虚拟化尺寸，坐标全错。真实分辨率 2560×1440。
  - UI 点击：ctypes `SetForegroundWindow`（先 Alt 脉冲绕 ForegroundLock）+ `SetCursorPos` + `mouse_event` 可模拟单击，不动键盘。脚本 `.shots/click_and_shot.py`。
- ZCode：Electron 应用，无本地监听端口，界面信息只能截图/模拟点击获取。主窗口句柄 985346。
