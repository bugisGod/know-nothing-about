### 用户反馈三问题的根因（BrainGraph.astro，行级）
1. **探索态双出口**：顶部 `.gf-back`（←退出探索）+ 底部 `#explore-exit`（EXIT EXPLORE）都退探索。
   附带：`.gf-back` 被**绑定两次 click**（3598 `flyBack` + 3657 分支版），聚焦态点一次跑两遍 flyBack
   （flyBack 首行幂等，暂无副作用）。
2. **聚焦态底部按钮说谎（核心）**：`flyTo` → `exitExplore(true)` 已把 `exploreMode=false`，
   但 keepUI 保留了按钮外观；点击时 `exitExplore()` 首行 `if(!exploreMode) return` 直接跳出，
   **只剩 flyBack 生效** → 写着 EXIT EXPLORE 实际只退聚焦。顶部 .gf-back 反而是对的。
3. **探索态无悬浮知识**：标签其实是显示的（探索态 hero 禁区还特意解除，4229-4231；
   opacity 0.85 可见）。真正问题是**标签 DOM 只有 cl-name + cl-count 两个 span**（3121-3124），
   `ClusterDef.desc` / `topicList` 从来没被星图用过 → 缺内容不是缺显示。

### 方案
- **A 出口收敛**：每状态只留一个主出口。探索态=底部 EXIT（顶部胶囊去按钮只当模式牌）；
  聚焦态=顶部 ←返回全景（底部 EXIT 隐藏）。显隐统一由主循环驱动：
  `const showExit = exploreMode && focusIdx < 0`。
- **B 标签三层渐进**（探索态专属，不动默认态视觉）：
  常态团名+篇数 → 探索态追加 desc 行 → hover/靠近浮出 topicList 话题词胶囊。
  desc 缺失降级：desc → topicList 前 3 → 「NN 篇文章」。

### 实测抓到 2 个回归（同一根因：`.show` 归属权没统一到 syncExploreLayer）
用 `.shots/test-explore-state.mjs`（CDP+Edge，五阶段快照）验证：
| 阶段 | border | exit | bar胶囊 | 文案 | 判定 |
|---|---|---|---|---|---|
| 1 默认态 | F | F | F | "" | ✅ |
| 2 漫游态 | T | T | T | 自由探索 | ✅ back 隐藏（双出口已消除）|
| 3 聚焦态 | T | F | T | ai | ✅ back 可见=返回全景（说谎已修）|
| 4 退回漫游 | T | T | **F** | **ai** | ❌ 胶囊消失 + 文案残留 |
| 5 退出探索 | F | F | F | ai | ✅ |

路径 A（`.shots/test-explore-paths.mjs`，漫游态**直接**点 EXIT，不经聚焦）：
→ border/exit 灭 ✅，但 **bar=true 残留 + aria=false** ❌。

- Bug A：漫游态直接退出 → 胶囊残留。因 `exitExplore()` 删掉了
  `focusBar.classList.remove('show')` / `aria-hidden=true`，syncExploreLayer 没接管。
- Bug B：聚焦退回漫游 → 胶囊消失+文案残留。因 `flyBack()` 里 remove('show')，
  而原来靠 `resumeExplore → enterExplore()` 恢复显示与文案的那条路被删了。

### 修复（给用户的方案）
syncExploreLayer 里补两件事，并删 flyBack 里的 remove('show')：
```js
focusBar.classList.toggle('show', exploreMode);              // 漫游/聚焦都显示，默认态隐藏
focusBar.setAttribute('aria-hidden', String(!exploreMode));
if (showExit) { /* 脏检查后写回 '自由探索' / '靠近星团查看 · 点击进入分类' */ }
```
